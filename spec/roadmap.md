# Roadmap

Not built yet, roughly in priority order:

- Macro and behavior editing (hold-tap parameters, new macros) instead of read-only source.
- Layer reordering with automatic renumbering of `&mo` / `&lt` / `&to` / `&tog` / `&sl` references and combo/conditional-layer layer lists.
- Conditional layers editing.
- Optional C preprocessor pass (`cpp -P`) to display macro-generated keymaps read-only.
- Built-in layouts for common keyboards when the repository has none.
- Copy/paste and drag-and-drop of key bindings; multi-select.
- Keymap image export.
